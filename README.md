# 코드 실험실

HTML 코드를 붙여 넣거나 파일을 올리면 바로 실행해서 눌러 보고, 오류와 확인 결과를 기록하는 도구입니다.

## 쓰는 법
- 폰이나 PC 브라우저에서 이 저장소의 GitHub Pages 주소를 열고, 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.
- 넣은 코드, 체크 표시, 메모는 열어 본 기기의 브라우저에만 저장됩니다. 서버로 보내지 않고, 다른 기기에서는 보이지 않으며, 브라우저 데이터를 지우면 사라집니다.
- 한 파일로 된 HTML만 실행됩니다. 서버 연결, API 키가 필요한 기능은 확인할 수 없습니다.
- 출처를 모르는 코드는 넣지 마세요.

## 파일
- `index.html` 실험실 본체
- `manifest.webmanifest`, 아이콘 파일들: 홈 화면 앱 설정
- `sw.js`: 인터넷 없이도 열리게 하는 저장 기능. 새 버전은 네트워크를 먼저 확인합니다.
- `.nojekyll`: GitHub Pages가 파일을 그대로 올리게 하는 표시
