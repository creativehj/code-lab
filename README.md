# 코드 실험실

HTML·JavaScript와 파이썬 코드를 넣으면 바로 실행해 보고, 오류와 확인 결과를 기록하는 도구입니다.

## 쓰는 법
- 폰이나 PC 브라우저에서 이 저장소의 GitHub Pages 주소를 열고, 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.
- 기본은 저장하지 않습니다. 새로고침하거나 닫으면 넣은 코드와 파일, 메모가 사라집니다. "이 기기에 테스트 저장하기"를 켠 경우에만 이 브라우저에 저장되고, 서버로는 보내지 않습니다.
- 웹 모드: 한 파일로 된 HTML을 실행하고, 자동 탐색(무작위로 눌러 보기)과 코드에서 뽑은 확인 항목을 보여 줍니다.
- 파이썬 모드: 파일·폴더·zip을 올리면 브라우저 안에서(Pyodide) unittest 또는 지정한 파일을 실행합니다. 처음 한 번 실행기를 내려받아야 해서 인터넷이 필요합니다.
- 서버 연결, API 키, 네트워크가 필요한 기능은 확인할 수 없습니다.
- 출처를 모르는 코드는 넣지 마세요.

## 파일
- `index.html` 실험실 본체
- `manifest.webmanifest`, 아이콘 파일들: 홈 화면 앱 설정
- `sw.js`: 인터넷 없이도 열리게 하는 저장 기능. 새 버전은 네트워크를 먼저 확인합니다.
- `.nojekyll`: GitHub Pages가 파일을 그대로 올리게 하는 표시
